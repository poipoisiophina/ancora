Troubleshooting ancora

Quick fixes for the common problems.

No anchor icon in the tray

Start SteamVR; ancora starts with it. Or run %LOCALAPPDATA%\ancora\ancora.exe. The icon can hide behind the small up arrow in the tray.

Installer says SteamVR is running

Close SteamVR fully, also from the tray, then press OK.

Still drifting

Open the panel. If the card says Not corrected, switch it on. If it drifts with your thumb on the stick, use Tune and apply a deadzone.

A controller shows Not connected

Wake the controller or check its battery. If it still shows that while the controller works in games, restart SteamVR with the controller already on.

I cannot walk slowly any more

Your deadzone is too high. Lower it or turn it off.

Valve Index controllers

Not supported yet. ancora does nothing on Index controllers.

Game does not use SteamVR

ancora only works for games that run through SteamVR.

Still stuck? Open the panel, Diagnostics, Copy diagnostics, and send that text with your question on GitHub.
